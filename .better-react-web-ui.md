## Design Context

### Users

Customer business administrators configure agent behavior and review outcomes; voice engineers test providers and diagnose realtime behavior; platform administrators own protected prompts, provider policy, and deployment; operators review calls and analytics.

### Brand Personality

Calm, precise, operational, and Telugu-first. Three words: **confident, agentic, operational**. The marketing site should feel like Outpero's India-first voice employee energy with Opero's editorial production-grade restraint. Consoles should create confidence and clarity rather than feel like a demo.

### Aesthetic Direction

Dark canvas `#06090d`, teal accent `#3dd6c6`, gold Telugu `#e8c468`, blue telemetry `#4db5ff`. Instrument Serif display + DM Sans body + JetBrains Mono telemetry. Marketing uses cinematic scroll chapters (HeroParallax, PinnedReveal, TiltCard) from the cinematic-scroll skill. Consoles are denser operational dashboards. Avoid generic card walls, neon AI purple, multi-stop gradients, and provider-first complexity.

Canonical tokens: `DESIGN.md`.

### Implementation Defaults

Next.js 14 App Router in `web/` with TypeScript and Tailwind CSS v3. Custom primitives in `web/components/ui` (not a full shadcn install). No form/table/virtualization library yet — use native markup with shared console components. Live voice stays in client components. Vanilla `client/` is historical reference only.

### Design Principles

1. Design the workflow before the shell: configure, test, inspect, compare, promote.
2. Establish hierarchy through spacing, weight, and grouping before adding color.
3. Keep one clear primary action per screen and progressively disclose advanced controls.
4. Separate customer-editable business logic from protected platform behavior.
5. Always show draft/active version, validation status, environment, and deployment impact.
6. Separate per-call debugging from fleet analytics.
7. Build complete loading, empty, partial, error, permission, and recovery states.
8. Motion is transform + opacity only, gated by `prefers-reduced-motion`.
